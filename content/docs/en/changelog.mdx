<TimelineEntry version="v0.2.1" date="2026-09-02">
  <Fragment slot="features">
    - **Release announcements** — the bot now posts a message on your server whenever a new version ships. Each announcement is sent once per server, and a server that installs the bot after a release does not receive that release's announcement
    - **`/settings` command** — configure the bot per server, reserved to members with the **Manage Server** permission. `announcement-channel` picks where announcements land, `announcements` turns them on or off with an optional `@everyone` mention, `show` displays the current configuration
    - **`/about` command** — bot version, website link, Terms of Use and Privacy Policy, available to every member
    - **Welcome message** — the bot introduces `/add`, `/list` and `/settings` when it joins a server, picking the system channel or the first channel it can write in
    - **Announcement fallback** — with no channel configured, announcements land in the last channel the bot was used in, with a notice explaining how to set a dedicated one
  </Fragment>
  <Fragment slot="fixes">
    - **Channel permission check** — `/settings announcement-channel` verifies the bot can actually post in the chosen channel and names the missing permission instead of failing silently later
    - **`@everyone` safety** — the mention stays off unless an admin opts in, and a missing **Mention Everyone** permission downgrades to a plain message rather than blocking the announcement
  </Fragment>
</TimelineEntry>

<TimelineEntry version="v0.2.0" date="2026-09-01">
  <Fragment slot="features">
    - **`/edit` command** — Modify the type, rarity, map or time of an objective already reported, instead of removing and re-adding it
    - **Flexible time input** — `/add` and `/edit` accept `1h30`, `1h`, `90`, `45m`, `02:30` and more; a bare number means minutes
    - **Autocomplete selection** — `/edit` and `/remove` list your server's active objectives instead of requiring a typed index
    - **Safer selection** — an objective picked from autocomplete carries a fingerprint, so a shifting list can no longer cause the wrong objective to be edited or removed
  </Fragment>
  <Fragment slot="fixes">
    - **Index resolution** — indexes now resolve against the active objectives shown in `/list`. Previously an expired objective could shift the list and make `/remove` delete a different objective than the one targeted
    - **Reporter name** — the objective line now credits the member by their server nickname instead of their global account name
  </Fragment>
</TimelineEntry>

<TimelineEntry version="v0.1.0" date="2025-06-01">
  <Fragment slot="features">
    - **`/add` command** — Report Black Zone objectives with type, rarity, map, and time remaining
    - **`/list` command** — View all active objectives grouped by category (Nodes, Cores, Vortexes)
    - **`/remove` command** — Delete objectives with permission checks (owner, Manage Messages, Administrator)
    - **276 Black Zone maps** with autocomplete search
    - **6 objective types** — Fiber node, Hide node, Ore node, Wood node, Core, Vortex
    - **9 rarity levels** — 4.4–8.4 for nodes, Green/Blue/Purple/Gold for cores and vortexes
    - **Duplicate detection** — prevents duplicate reports within an 8-minute window
    - **Maintenance detection** — flags objectives that span the 10:00 UTC daily maintenance
    - **Auto-cleanup** — cron job removes expired objectives every 30 minutes
    - **Multi-server isolation** — each Discord server has its own independent objective list
    - **Docker deployment** — production-ready multi-stage build with non-root user and read-only filesystem
  </Fragment>
</TimelineEntry>

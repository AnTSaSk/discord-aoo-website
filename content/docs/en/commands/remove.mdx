The `/remove` command deletes a reported objective from your server's active list.

## Syntax

```
/remove index:<number>
```

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `index` | Autocomplete | Yes | The objective to remove. Start typing and pick it from the suggestions. |

## Permissions

You can remove an objective if you meet **any one** of these conditions:

| Who | Condition |
|-----|-----------|
| **Original reporter** | You added the objective with `/add` |
| **Manage Messages** | You have the Manage Messages permission |
| **Administrator** | You have the Administrator permission |

If you don't have permission, the bot responds with an error message (visible only to you).

## Selecting the objective

Start typing in the `index` field and the bot lists your server's active objectives:

```
#1 — Vortex Gold Thetford (14:20 UTC)
#2 — Ore node 8.4 Avalanche Ravine (16:05 UTC)
#3 — Core Purple Martlock (18:45 UTC)
```

The list shows up to **25** objectives and covers **active** ones only — the index refers to an objective's position among the objectives still running, which is exactly what [`/list`](/docs/commands/list/) displays.

<Callout variant="tip">Pick an entry from the suggestions instead of typing the number. A picked entry carries a fingerprint of the objective, so if the list shifts between opening the command and submitting it, the bot refuses rather than removing the wrong objective.</Callout>

Typing the number by hand still works, but without that safeguard.

## Behavior

### Message Refresh

After a successful removal, the bot automatically refreshes the objective list message to reflect the change. Index numbers are recalculated.

### Cooldown

This command has a **2-second cooldown** per user.

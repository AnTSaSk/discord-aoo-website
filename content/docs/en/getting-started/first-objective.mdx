This tutorial walks you through reporting your first Albion Online Black Zone objective. No configuration is needed; Albion Online Objectives (AOO) works immediately after [installation](/docs/getting-started/installation/).

## Reporting an Objective

1. **Open Discord** and go to any channel where the bot has access.

2. **Type `/add`**. Discord will show the command with its four parameters.

<ScrollReveal animation="fade-in">
  <Screenshot src="/screenshots/add-autocomplete.png" alt="Discord autocomplete showing /add command parameters" mode="discord" />
</ScrollReveal>

3. **Fill in the parameters:**

   | Parameter | What to enter | Example |
   |-----------|---------------|---------|
   | `type` | The objective type (autocomplete) | `Ore node` |
   | `rarity` | The rarity, tier, or portal size (autocomplete) — leave empty for a [Dragon attack](/docs/guides/portals-and-dragons/) | `7.4` |
   | `map` | The Black Zone map name (autocomplete) | `Murdergulch Ravine` |
   | `time` | Time remaining until spawn — [several formats accepted](/docs/commands/add/#accepted-time-formats) | `1h30` |

4. **Press Enter** to submit. Albion Online Objectives confirms the objective was added.

<ScrollReveal animation="fade-in">
  <Screenshot src="/screenshots/add-success.png" alt="Ephemeral success message after adding an objective" mode="discord" />
</ScrollReveal>

<Callout variant="tip">All three parameters with text values (`type`, `rarity`, and `map`) support **autocomplete**. Start typing and select from the suggestions. For maps, you can type any part of the name (beginning, middle, or end) and matching results will appear. Type and rarity also filter each other: if you select a node rarity (e.g., 7.4), only node types appear, and vice versa.</Callout>

## Viewing Active Objectives

Type `/list` to see all objectives currently reported for your server. The bot displays them grouped into five categories: resource nodes (Fiber, Hide, Ore, and Wood), energy cores, vortexes, Ancient Lands Portals (timed portals in three sizes), and Dragon attacks.

Each entry shows the rarity (a size for portals, nothing for Dragons), time with a live countdown, and the map name.

## What Happens Next

- If someone tries to add the same objective within an 8-minute window, the bot **rejects the duplicate**.
- Expired objectives are **cleaned up automatically** every 30 minutes.
- When the calculated spawn time crosses the 10:00 UTC daily maintenance window, the bot **flags the objective**.

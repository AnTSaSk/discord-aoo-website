## Permissions requises

Albion Online Objectives (AOO) a besoin des permissions suivantes pour fonctionner correctement :

| Permission | Raison |
|-----------|--------|
| **Voir les salons** | Accéder aux salons où les commandes sont utilisées |
| **Envoyer des messages** | Publier les listes d'objectifs et les réponses |
| **Voir les anciens messages** | Retrouver les anciens messages du bot pour les mettre à jour |
| **Gérer les messages** | Supprimer les messages d'objectifs obsolètes lors du rafraîchissement |
| **Utiliser les commandes slash** | Enregistrer et répondre aux commandes `/add`, `/list`, `/remove` |

## Message de bienvenue

Dès son arrivée, le bot publie un court message de bienvenue présentant `/add`, `/list` et `/settings`. Il choisit le salon système de votre serveur s'il peut y écrire, sinon le premier salon textuel accessible. Si aucun salon ne l'est, le message est omis. Le bot fonctionne malgré tout.

## Configuration facultative

Albion Online Objectives fonctionne immédiatement après l'installation. N'importe quel membre peut rapporter des objectifs avec `/add` : aucune commande de configuration n'est requise.

Un réglage mérite toutefois une minute d'attention d'un administrateur : [`/settings announcement-channel`](/docs/commands/settings/) choisit où atterrissent les annonces de version. Sans lui, elles se replient sur le dernier salon où le bot a été utilisé.

Les annonces sont **activées** par défaut et ne mentionnent jamais `@everyone` sans qu'un administrateur l'ait explicitement autorisé.

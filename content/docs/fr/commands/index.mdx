Toutes les interactions avec Albion Online Objectives (AOO) passent par les commandes slash Discord. Tapez `/` dans n'importe quel salon où le bot a accès pour voir les commandes disponibles.

<Callout variant="info">Les commandes ont des temps de recharge pour éviter le spam : 2 secondes pour /add, /edit, /remove et /about, 5 secondes pour /list.</Callout>

## Commandes

| Commande | Description | Temps de recharge |
|----------|-------------|-------------------|
| [`/add`](/docs/commands/add/) | Rapporter un nouvel objectif de Black Zone | 2 secondes |
| [`/list`](/docs/commands/list/) | Voir tous les objectifs actifs de votre serveur | 5 secondes |
| [`/edit`](/docs/commands/edit/) | Modifier un objectif déjà rapporté | 2 secondes |
| [`/remove`](/docs/commands/remove/) | Supprimer un objectif rapporté | 2 secondes |
| [`/settings`](/docs/commands/settings/) | Configurer les annonces de version du serveur | — |
| `/about` | Version du bot, site et documents légaux | 2 secondes |

## Démarrage rapide

Vous découvrez Albion Online Objectives ? Suivez le tutoriel [Rapporter votre premier objectif](/docs/getting-started/first-objective/) pour apprendre le fonctionnement de base :

1. **Rapportez** un objectif trouvé en Black Zone avec [`/add`](/docs/commands/add/)
2. **Consultez** tous les objectifs actifs de votre guilde avec [`/list`](/docs/commands/list/)
3. **Corrigez** une erreur avec [`/edit`](/docs/commands/edit/), sans supprimer puis recréer
4. **Supprimez** une entrée expirée ou incorrecte avec [`/remove`](/docs/commands/remove/)

Un administrateur peut ensuite choisir où atterrissent les annonces de version avec [`/settings`](/docs/commands/settings/).

## Permissions

<Badge variant="green">Aucune permission requise</Badge> `/add`, `/list` et `/about` sont accessibles à tous les membres de votre serveur.

`/edit` et `/remove` nécessitent l'une des conditions suivantes pour modifier ou supprimer le rapport d'**un autre joueur** :

- Permission **Administrateur**
- Permission **Gérer les messages**
- Être l'auteur du rapport original

[`/settings`](/docs/commands/settings/) est la seule commande soumise à une permission de serveur : elle exige **Gérer le serveur**, et les membres qui n'en disposent pas ne la voient pas du tout.

## `/about`

`/about` répond en privé avec la version courante du bot et les liens vers ce site, les [Conditions d'Utilisation](/fr/terms) et la [Politique de Confidentialité](/fr/privacy). Tous les membres peuvent l'utiliser.

Consultez la page dédiée de chaque commande pour les détails complets des paramètres et des exemples.

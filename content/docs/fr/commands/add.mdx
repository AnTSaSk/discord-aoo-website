La commande `/add` rapporte un nouvel objectif de Black Zone dans la liste de suivi de votre serveur. Tous les membres du serveur peuvent utiliser cette commande.

## Syntaxe

```
/add type:<type> [rarity:<rarity>] map:<map> time:<time>
```

## Paramètres

Les paramètres `type`, `map` et `time` sont **obligatoires**. `rarity` est facultatif au niveau de Discord, mais le bot l'attend pour tous les types sauf `Dragon` (voir la [validation de la rareté](#validation-de-la-rareté) ci-dessous).

| Paramètre | Type | Description |
|-----------|------|-------------|
| `type` | Autocomplétion | Le type d'objectif — une des 8 valeurs (voir [types d'objectifs](/docs/guides/objective-types/)) |
| `rarity` | Autocomplétion | Tier pour les nodes (`4.4`–`8.4`), couleur pour les cores/vortex (`Green`, `Blue`, `Purple`, `Gold`) ou taille pour les portails (`Small`, `Medium`, `Large`). À laisser vide pour `Dragon`. |
| `map` | Autocomplétion | Nom de la carte de Black Zone — 276 cartes supportées (voir [liste des cartes](/docs/guides/black-zone-maps/)) |
| `time` | Texte | Temps restant avant l'apparition de l'objectif. Plusieurs formats sont acceptés — voir [ci-dessous](#formats-de-temps-acceptés). Exemple : `1h30` ou `02:30` (2 heures et 30 minutes à partir de maintenant) |

### Valeurs de type

| Type | Catégorie |
|------|----------|
| `Fiber node` | Node |
| `Hide node` | Node |
| `Ore node` | Node |
| `Wood node` | Node |
| `Core` | Core |
| `Vortex` | Vortex |
| `Ancient Lands Portal` | Portal |
| `Dragon` | Dragon |

### Valeurs de rareté

**Pour les nodes :** `4.4`, `5.4`, `6.4`, `7.4`, `8.4`

**Pour les cores et vortex :** `Green`, `Blue`, `Purple`, `Gold`

**Pour les Ancient Lands Portals :** `Small`, `Medium`, `Large`. La taille reflète la capacité de groupe en jeu (1–5, 5–7 et 15–20 joueurs ; voir le [guide des portails et Dragons](/docs/guides/portals-and-dragons/))

**Pour les Dragons :** aucune, laissez le champ vide

### Validation de la rareté

Le bot vérifie que la rareté correspond à la famille du type choisi. Cinq issues sont possibles :

| Type choisi | Rareté fournie | Résultat |
|-------------|----------------|----------|
| Type à rareté (node, core, vortex, portail) | De sa propre famille | Accepté |
| Type à rareté | D'une autre famille | Refusé — combinaison type/rareté invalide |
| Type à rareté | Laissée vide | Refusé — une rareté est requise pour ce type |
| `Dragon` | Laissée vide | Accepté |
| `Dragon` | Fournie | Refusé — un Dragon ne prend aucune rareté |

## Autocomplétion

Les paramètres `type`, `rarity` et `map` supportent tous la fonctionnalité d'autocomplétion de Discord. Commencez à taper et les options correspondantes apparaîtront. Pour les cartes, la recherche fonctionne sur n'importe quelle partie du nom : début, milieu ou fin.

De plus, les champs `type` et `rarity` sont contextuels. L'autocomplétion de rareté ne propose que la famille du type déjà choisi : les tiers pour un node, les couleurs pour un core ou un vortex, les tailles pour un Ancient Lands Portal. Une fois `Dragon` sélectionné, elle ne propose **rien**, puisqu'un Dragon ne prend aucune rareté. Le filtrage fonctionne aussi dans l'autre sens : sélectionner une rareté de node (4.4–8.4) filtre la liste des types pour n'afficher que les nodes.

## Exemples

```
/add type:Ore node rarity:7.4 map:Murdergulch Ravine time:02:30
/add type:Core rarity:Gold map:Hightree Enclave time:01:15
/add type:Vortex rarity:Purple map:Deepwood Gorge time:04:00
/add type:Ancient Lands Portal rarity:Medium map:Deepwood Gorge time:00:45
/add type:Dragon map:Everwinter Peak time:1h15
```

## Comportement

### Prévention des doublons

<Callout variant="info">Albion Online Objectives empêche automatiquement les doublons. Si le même type d'objectif, la même rareté et la même carte sont rapportés dans un intervalle de 8 minutes, le bot rejette le rapport.</Callout>

Si un objectif avec le même type, la même rareté et la même carte existe déjà dans une **fenêtre de 8 minutes** (±4 minutes par rapport au temps rapporté), le bot rejette le nouveau rapport et vous en informe. Cela évite les doublons accidentels lorsque plusieurs membres de la guilde repèrent le même objectif. Les Dragons sont couverts comme les autres types : un second rapport de Dragon sur la même carte dans la fenêtre est rejeté.

### Détection de la maintenance

<Callout variant="warning">Lorsque l'heure d'apparition calculée chevauche la fenêtre de maintenance quotidienne de 10:00 UTC, le bot ajoute un avertissement à l'objectif.</Callout>

La maintenance quotidienne des serveurs d'Albion Online a lieu à **10:00 UTC**. Si l'heure d'apparition calculée chevauche cette fenêtre, le bot l'indique automatiquement, et vos compagnons de guilde savent que l'objectif pourrait ne pas survivre au redémarrage du serveur.

### Temps de recharge

Cette commande a un **temps de recharge de 2 secondes** par utilisateur.

### Formats de temps acceptés

Le paramètre `time` accepte plusieurs notations. Un nombre seul correspond toujours à des **minutes**.

| Saisie | Interprétation |
|--------|---------------|
| `1:30` | 1 heure 30 minutes |
| `02:30` | 2 heures 30 minutes |
| `1h30` | 1 heure 30 minutes |
| `1h30m` | 1 heure 30 minutes |
| `1h 30` | 1 heure 30 minutes |
| `1h 30m` | 1 heure 30 minutes |
| `1h` | 1 heure |
| `90` | 90 minutes |
| `45m` | 45 minutes |
| `90m` | 90 minutes |

La valeur est un **délai à partir de maintenant**, jamais une heure absolue. Les formats non reconnus sont rejetés avec un message listant les formats acceptés.

### Limites de temps

Le délai accepté est plafonné selon le type. Pour les Ancient Lands Portals, le plafond dépend de la taille ; tous les autres types utilisent la limite générale de 24 heures :

| Type | Délai maximum |
|------|---------------|
| `Ancient Lands Portal` — `Small` | 30 minutes |
| `Ancient Lands Portal` — `Medium` | 60 minutes |
| `Ancient Lands Portal` — `Large` | 180 minutes |
| Tous les autres types | 1440 minutes (24 heures) |

Ces plafonds sont un **garde-fou contre les fautes de frappe**, pas une règle du jeu : ils attrapent une coquille comme `100` tapé à la place de `10`. Toute valeur inférieure est acceptée telle quelle, et le bot ne déduit jamais une heure d'ouverture à partir de la taille d'un portail : un portail repéré tardivement se rapporte avec le temps qu'il reste réellement. Lorsqu'une valeur de temps est à la fois mal formée et hors plage, c'est l'**erreur de format** qui est signalée en premier.

## Après l'ajout

Une fois ajouté, l'objectif apparaît dans le résultat de [`/list`](/docs/commands/list/). Pour supprimer une entrée incorrecte, utilisez [`/remove`](/docs/commands/remove/).

La commande `/remove` supprime un objectif rapporté de la liste active de votre serveur.

## Syntaxe

```
/remove index:<number>
```

## Paramètres

| Paramètre | Type | Obligatoire | Description |
|-----------|------|----------|-------------|
| `index` | Autocomplétion | Oui | L'objectif à supprimer. Commencez à saisir et choisissez-le dans les suggestions. |

## Permissions

Vous pouvez supprimer un objectif si vous remplissez **l'une** de ces conditions :

| Qui | Condition |
|-----|-----------|
| **Auteur du rapport** | Vous avez ajouté l'objectif avec `/add` |
| **Gérer les messages** | Vous disposez de la permission Gérer les messages |
| **Administrateur** | Vous disposez de la permission Administrateur |

Si vous n'avez pas la permission requise, le bot répond avec un message d'erreur (visible uniquement par vous).

## Sélectionner l'objectif

Commencez à saisir dans le champ `index` : le bot liste les objectifs actifs de votre serveur.

```
#1 — Vortex Gold Thetford (14:20 UTC)
#2 — Ore node 8.4 Avalanche Ravine (16:05 UTC)
#3 — Core Purple Martlock (18:45 UTC)
```

La liste affiche jusqu'à **25** objectifs et ne couvre que les objectifs **actifs** : l'index correspond à la position d'un objectif parmi ceux encore en cours, c'est-à-dire exactement ce qu'affiche [`/list`](/docs/commands/list/).

<Callout variant="tip">Choisissez une entrée dans les suggestions plutôt que de saisir le numéro. Une entrée choisie embarque une empreinte de l'objectif : si la liste change entre l'ouverture de la commande et sa validation, le bot refuse au lieu de supprimer le mauvais objectif.</Callout>

La saisie manuelle du numéro reste possible, mais sans cette protection.

```
/remove index:1
```

## Comportement

### Rafraîchissement du message

Après une suppression réussie, le bot rafraîchit automatiquement le message de la liste des objectifs pour refléter le changement. Les numéros d'index sont recalculés.

### Temps de recharge

Cette commande a un **temps de recharge de 2 secondes** par utilisateur.

## Commandes associées

- [`/list`](/docs/commands/list/) — Voir les objectifs actifs et leurs numéros d'index
- [`/add`](/docs/commands/add/) — Rapporter un nouvel objectif
